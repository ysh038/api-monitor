# 명세: 레이아웃 고정 · 토글 애니메이션

- 작성일: 2026-09-29
- 상태: 구현됨

## 목표

필터를 바꿔 요약 제목의 숫자나 목록 길이가 달라지면 **목록 위쪽(상단 바·요약·필터·시간대별 막대)이 위아래·좌우로 출렁인다.** 목록이 늘든 줄든 위쪽은 제자리에 있어야 한다. 측정한 원인:

1. **스크롤바**: 목록이 짧아져 세로 스크롤바가 사라지면 화면 폭이 1385px → 1400px 로 바뀌어 전체가 15px 좌우로 밀린다.
2. **요약·시간대별 막대 높이**: 결과가 없으면 설명 줄과 외부 서버 카드 줄이 사라져 요약이 153px → 34px 로 줄고, 시간대별 막대(88px)도 통째로 사라져 목록이 위로 올라간다. 설명이 두 줄로 넘치거나 카드가 두 줄로 넘쳐도 높이가 바뀐다.
3. **글자 폭**: 상단 바의 Mock 결과 메시지가 나타나면 오른쪽 정렬된 버튼들이 왼쪽으로 밀린다. 선택된 칩·버튼 글자가 굵어지면 옆 칩이 조금 밀린다.

또 버튼 묶음(전체/들어온 요청/외부 호출, 자동/라이트/다크)은 선택 표시가 **순간이동**한다. 미끄러지듯 옮겨 가야 한다.

## 범위 밖

- 목록(표) 자체의 높이 변화. 목록은 늘고 줄어도 된다.
- 좁은 화면(760px 이하)에서의 줄바꿈 배치.
- 상세 패널 애니메이션.

## 수용 기준

**레이아웃 고정**
- [x] L1: 요약 영역 높이는 결과가 있을 때(실패한 외부 서버 카드 있음), 카드가 없을 때, 결과가 0건일 때 모두 같다. — 2026-09-30: 요약이 고정 두 줄(D0)이 되면서 카드 줄이 없어져 높이가 항상 같다.
- [x] L2: 요약 제목과 설명은 한 줄로 고정한다. 넘치면 말줄임하고 전체 문장은 `title`로 볼 수 있다.
- [x] L3: 실패한 외부 서버 카드가 많아도 한 줄을 유지한다(넘치면 가로 스크롤).
- [x] L4: 세로 스크롤바 자리를 항상 확보한다(`scrollbar-gutter: stable`). 스크롤바가 생기거나 사라져도 가로 위치가 변하지 않는다.
- [x] L5: 상단 바의 Mock 결과 메시지가 나타나거나 사라져도 다른 버튼 위치가 변하지 않는다.
- [x] L6: 선택된 칩·버튼의 글자가 굵어져도 버튼 폭이 변하지 않는다.
- [x] L7: 요약·목록 머리의 숫자는 고정폭 숫자(`tabular-nums`)로 쓴다.
- [x] L8: 시간대별 막대는 결과가 0건이어도 제목·빈 막대 영역·축을 그대로 두어 높이가 같다 (예전에는 통째로 사라져 목록이 88px 올라왔다).

**토글 애니메이션**
- [x] M1: 버튼 묶음의 선택 표시가 새로 고른 버튼 위치·폭으로 미끄러져 옮겨 간다(`--duration-base`).
- [x] M2: 처음 그릴 때는 미끄러지지 않고 바로 선택한 자리에 있다.
- [x] M3: 버튼 묶음 크기가 바뀌면(창 크기 등) 선택 표시가 다시 맞춰진다.
- [x] M4: 상태 칩을 켜고 끌 때 배경·테두리·글자색이 부드럽게 바뀐다.
- [x] M5: OS "동작 줄이기"가 켜져 있으면 애니메이션 없이 바로 바뀐다(tokens.css 전역 규칙).
