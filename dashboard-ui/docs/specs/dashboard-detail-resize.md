# 명세: 상세 패널 폭 조절

- 작성일: 2026-10-01
- 상태: 확정 (2026-10-01 사용자 요청)

## 목표

오른쪽 상세 패널은 560px 고정이라, 긴 경로·스택트레이스·바디를 볼 때는 좁고 목록을 같이 보고 싶을 때는 넓다.
패널 왼쪽 가장자리를 마우스로 끌어 폭을 바꿀 수 있게 하고, 어떤 폭에서도 안의 내용이 깨지지 않게 한다.

## 범위 밖

- 패널을 왼쪽·아래로 옮기기, 패널을 고정(오버레이 아님) 칼럼으로 바꾸기
- 서버에 폭 저장 (브라우저마다 기억)

## 수용 기준

**S** = 스토리 테스트.

- [x] R1 (S): 패널 왼쪽 가장자리에 폭 조절 손잡이가 있다 — `role="separator"`, `aria-orientation="vertical"`, `aria-label="상세 패널 폭 조절"`, `aria-valuenow`(현재 폭 px)·`aria-valuemin`·`aria-valuemax`, 키보드로 닿는다(`tabIndex=0`).
- [x] R2 (S): 손잡이를 끌면 패널 폭이 끈 만큼 바뀐다(왼쪽으로 끌면 넓어진다). 최소 400px, 최대 `화면 폭 − 80px`(뒤 배경을 눌러 닫을 자리를 남긴다)로 제한한다. 기본 폭은 560px.
- [x] R3 (S): 손잡이에 포커스가 있을 때 ←는 16px 넓히고 →는 16px 좁힌다. Shift 를 누르면 64px.
- [x] R4 (S): 손잡이를 더블클릭하면 기본 폭(560px)으로 돌아간다.
- [x] R5 (S): 조절한 폭은 이 브라우저에 기억해서 다음에 패널을 열 때 그 폭으로 연다. 저장소를 못 쓰면(사생활 보호 모드 등) 기본 폭으로 동작한다.
- [x] R6 (확인): 화면 폭 760px 이하에서는 패널이 전체 폭이고 손잡이는 보이지 않는다.
- [x] R7 (S): 상세 내용은 패널 폭에 맞춘다 — 최소 폭(400px)에서 가로로 넘치지 않고(코드 블록은 자기 안에서만 가로 스크롤), 호출 흐름 레인의 막대 칸이 보인다. 좁을 때(480px 이하)는 레인 이름·시간 칸을 줄인다.

## 설계 메모

- 드래그 중에는 React 상태를 바꾸지 않고 패널의 CSS 변수(`--drawer-width`)만 바꾼다 — 상세 내용이 매 움직임마다 다시 렌더링되지 않게. 손을 떼면 상태·저장소에 반영한다.
- 내용 반응은 화면 폭이 아니라 패널 폭 기준이어야 하므로 패널 본문을 CSS 컨테이너(`container-type: inline-size`)로 둔다.
